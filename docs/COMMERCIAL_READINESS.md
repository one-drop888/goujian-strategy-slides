# Commercial readiness

**Documentation only.** This repository does not open accounts, collect payments, list products or promise launch dates. Nothing below is a shipping commitment or a certification.

## Community

The Community core remains free under Apache-2.0. That includes the native build, reasoning-plan validation, doctor, structural QA, documentation and defect fixes. No feature described as Community is gated behind a paid account.

## Supporter (future candidate)

A voluntary supporter option may be offered at **$5–9** as a future candidate. At this stage there is no checkout, account, payment link, product listing or entitlement. A supporter payment, if ever introduced, must not restrict the Apache-2.0 core or imply support for unverified platforms.

## Pro (future candidate)

Three future business workflow packs are candidates:

- **Executive Decision** — review, decision framing, actions and owners.
- **MultiSource Consolidation** — source ledgers, deduplication and evidence limits.
- **Research Strategy** — sample/method constraints, findings and qualified recommendations.

They would reuse the same presentation engine and library. There is **no second rendering engine**, no claim of autonomous analysis and no shipping date. These names are not current products or entitlements.

## Agensi and other agent hosts

Agensi's public materials state that skills execute inside an existing agent rather than supplying a runtime, and describe frontmatter/file-type screening plus packaging and upload steps. Those pages do not test this repository's Node/Python runtime.

Accordingly:

- Local Node.js/Python execution through Agensi is **NOT_VERIFIED**.
- No Agensi account, registry listing, payment or certification is claimed.
- Platform import and security scanning must be repeated on the target platform.
- Agent-hosted execution does not remove the need for local Node, Python, LibreOffice/Poppler and fonts when rendering is required.

## Social preview

GitHub's documented social-preview recommendation is **1280 × 640**. The repository includes a restrained 1280 × 640 image built from an actual V1.2 render:

`docs/visual/v1.2/social-preview-1280x640.png`

This file being ready is separate from GitHub repository settings. If no tool uploads it, a maintainer can set it manually:

1. Open repository **Settings → General**.
2. Find **Social preview** and choose **Edit**.
3. Upload `docs/visual/v1.2/social-preview-1280x640.png`.
4. Save, then refresh the repository link preview.
