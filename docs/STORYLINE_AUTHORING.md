# Storyline Authoring Guide

A Storyline describes **how a management question should be reasoned through**. It is not a fixed sequence of decorative page templates.

Add a Storyline only when an existing reasoning chain is materially insufficient.

Required fields in `skill/storylines/registry.json`:
- `id`
- `name`
- `triggers`
- `recommended_sequence`
- `management_questions`

A strong Storyline usually starts from a decision or problem and ends in an action/decision. Avoid department-only variants whose reasoning is identical to an existing Storyline.
