# Goujian Strategy Slides v1.0.0

构见·战略演示 — Presentation Intelligence for AI Agents.

**Think clearly. Structure strategically. Present decisively.**

This first public release connects management reasoning to a bounded, editable PPTX workflow: **Think → Structure → Visualize → Build → Validate**, using **Question → Evidence → Judgment → Action**.

- 28 storylines, 15 template recipes, 23 composition recipes, 15 profiles and 10 synthetic benchmark decks.
- 78 semantic entries with honest capability states: 65 implemented, 6 partial, 7 designed-only and rejected by the builder.
- Three rounds of visual inspection: larger readable type, open comparisons and KPI strips, cleaner native charts, meaningful table headers, preserved research limitations and clearer matrix/portfolio pages.
- Executable schema/payload validation, graphic-frame geometry checks, accurate unavailable-font status, isolated rendering and hash-bound visual review records.
- English/Chinese README, product overview and feasibility review, plus actual before/after render evidence.
- Fixed dependency versions and lockfile; clean installation and negative regression tests.

**Verdict: V1.0 RELEASE READY WITH KNOWN LIMITATIONS.**

Planner and visual repair remain agent/human assisted. Arbitrary PPTX editing is not lossless; fonts must be installed; geometry QA does not prove text fit. HTML, advanced chart archetypes, animations and native Windows/macOS/PowerPoint validation remain outside the proven V1 scope. See the [feasibility review](https://github.com/one-drop888/goujian-strategy-slides/blob/main/docs/FEASIBILITY_REVIEW.md).

Use `goujian-strategy-slides-v1.0.0.zip` for the optimized runtime or GitHub's source archive. If an asset named `original-candidate` is present, it is the unmodified input candidate retained for provenance, **not** the optimized runtime. ZIP files are not committed to the repository.
