## Non-negotiable decisions

- Preserve every V1.3 production capability and public full-source installation path. Do not remove measurement, image processing, Python, fonts, native objects, reasoning, analysis or QA to satisfy a text pattern.
- Static imports may replace unnecessary trusted-file dynamic loading, with standalone/module CLI parity checked. Do not hide, encode, alias or split execution patterns.
- Fixed-program argument-array subprocesses are distinct from shell command evaluation. Keep necessary process behavior explicit. Changes need an actual safety or maintainability justification and equivalence proof, not a token rename.
- Packaging follows real runtime/reference reachability and command contracts. Development tests/history/CI may be distributed separately, but production QA, agent instructions, reference assets, Bootstrap and Doctor remain available. Do not silently break documented runtime commands.
- Security scan must retain existing blocking rules, inventory all text feature matches with context, and distinguish executable behavior from inert tests/rules/docs. Pattern absence cannot prove enterprise acceptance.
- `CAPABILITY_PARITY_V1_3_0_TO_V1_3_1` must use locked baseline bytes, identical input/environment, native structural/data/object checks and actual renders. General zero-regression claims cannot exceed tested scope.
- Preserve v1.3.0; no force push/tag overwrite or release replacement. Qoder may publish only after Codex's independent acceptance, through the existing GitHub workflow.
