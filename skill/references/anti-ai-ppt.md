# Anti-AI-PPT Rules

The goal is **intentional editorial design**, not template completion.

## Hard red flags
- 4+ consecutive content slides with the same composition when the reasoning differs.
- Mechanical three-card grids for unrelated content.
- Bullet lists converted into rounded rectangles without semantic restructuring.
- Generic topic titles when a defensible conclusion exists.
- Decorative AI imagery, gradient blobs, sparkles or icons without information value.
- Huge type used to conceal lack of evidence.
- Unlabeled charts, missing units/periods, or fabricated sources.
- Repeated "insight" boxes that merely restate the chart.
- Content padded to reach a target slide count.
- Dense content compressed into too few pages to appear concise.

## Correction patterns
- Topic title → evidence-backed action title.
- Repeated cards → chart / comparison / matrix / tree / table / flow.
- Paragraph → evidence + annotation + implication.
- Decorative image → remove or replace with evidence-bearing visual.
- Same layout → choose composition from reasoning structure.
- One page with two competing messages → split.
- Two pages making one weak point → merge.

## Variation rule

Visual variation is not decoration. Change composition only when the reasoning structure changes. Repetition is acceptable for true scorecards, recurring regional pages or standardized operating reviews.
