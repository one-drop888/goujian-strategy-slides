# Content Planning

## Management logic

Default reasoning pattern:

**Question → Evidence → Judgment → Action**

A slide is not complete because it contains information. It is complete when the audience can understand what the evidence means and what follows from it.

## Action-title standard

Prefer titles that carry the conclusion:

- Weak: `渠道现状分析`
- Strong: `核心城市覆盖已基本完成，下一阶段应从扩点转向单店提效`

Action titles should normally contain at least one of:
- change / direction;
- gap / difference;
- cause;
- implication;
- choice;
- required action.

Do not force a conclusion when evidence is still exploratory. Research-method, agenda and section slides can use descriptive titles.

## Information-density standard

**High information density is not high text density.**

Preferred order:
1. chart / quantitative evidence;
2. relationship, process or causal structure;
3. table / scorecard / compact metric;
4. concise explanatory text.

## One-page test

Before rendering every content slide, answer:
1. What management question does this page answer?
2. What is the strongest evidence?
3. What is the judgment?
4. Does the visual structure match that reasoning?
5. Is an action/decision implied or explicit?
